# FCG 接口资料准入清单

## 1. 已确认

- 开放平台入口：`https://open.fusionconnectgroup.com/`
- 产品：G-Link Hotel API、F-Link Flight API。
- 接入方式：REST API；平台首页同时声明提供 Go、Java、Python SDK。
- 沙箱：平台注册后可申请。
- G-Link 与 F-Link 均使用开放平台 `X-OP-*` 网关签名。
- 签名包含方法、实际运行路径、排序查询串、原始请求体 SHA256、时间戳、nonce 和 App Key。
- G-Link 已确认轻量目的地、酒店静态信息、实时产品、可订校验、下单、支付、订单、取消、回调、结账、发票及余额能力。
- F-Link 已确认航班搜索、舱位、验价、下单、支付、订单详情、取消、退票、改签及基础数据能力。

## 2. 启动开发前必须取得

### 账号与环境

- 沙箱账号和应用。
- 沙箱 Base URL。
- 沙箱 `open_app_id`、`open_app_secret`。
- 出口 IP 白名单要求。
- 沙箱测试数据、测试酒店、测试航班和测试卡/授信账户。
- 生产准入流程、生产 Base URL、证书和切换窗口。

### 完整接口规范

- 已下载 OpenAPI JSON，当前版本为 2026-04-24；后续升级需要运行契约测试。
- 完整字段字典、枚举、必填条件和示例。
- 所有业务错误码、HTTP 状态码和是否允许重试。
- 限流规则、超时建议、SLA 和最大报文限制。
- 幂等规则、请求流水号规则和重复订单处理方式。
- 回调事件、签名验签、重试频率、顺序和去重规则。

### 酒店接口

- 城市/区域/酒店静态数据。
- 酒店搜索、酒店详情、设施与图片。
- 房型/房价、税费、币种和取消政策。
- 预订前验价/库存确认。
- 创建预订、查单、取消、退款。
- 特殊要求、儿童、加床、多人多房和入住人规则。
- 静态数据增量更新和图片授权规则。

### 机票接口

- 机场、城市、航司等基础数据。
- 航班搜索、运价、舱位、行李和退改规则。
- 运价校验。
- 乘机人及证件规则。
- 创建订单/占座、支付确认、出票。
- 订单查询、票号、行程单。
- 取消订单、退票、改签、航变。
- 国际机票、联程、往返、多程和儿童/婴儿规则。

### 商务与财务

- 采购价、佣金、服务费和税费定义。
- 预存/授信/月结模式及额度接口。
- 币种、汇率、舍入精度和汇损承担。
- 对账单、结算单、发票和差异处理接口或文件。
- 退款到账时效与上游责任边界。

### 合规与支持

- 数据处理协议和个人信息字段清单。
- 数据存储地域、跨境规则和保留期限。
- PCI DSS 责任边界或支付渠道方案。
- 技术支持联系人、工单渠道和 P1/P2 升级 SLA。
- 沙箱和生产维护窗口、变更通知周期、版本废弃策略。

## 3. 当前阻塞项

G-Link/F-Link Skills、当前 OpenAPI JSON、签名客户端和必接交易适配器已经完成。目前真实沙箱联调仍依赖：

- 沙箱 `open_app_id/open_app_secret`。
- 应用同时开通 G-Link 与 F-Link 的 `sandbox_active` 权限。
- 平台沙箱测试酒店、航班、支付/授信数据。
- 回调公网地址或沙箱允许的回调调试方案。
- 可公开访问的 G-Link 订单状态回调地址及平台回调配置。

在凭证到位前，工程使用 Mock 模式运行；不得自行猜测真实请求字段，也不得把生产凭证用于沙箱。
