# 账户设置页交互缺陷与回归报告

测试日期：2026-08-03  
环境：本地前端 `http://localhost:5174` + 本地 API + FCG Sandbox  
范围：账户设置页、页头企业入口与帮助入口；不包含性能测试。

## 结论

用户反馈属实。原测试用例 `G-06` 只验证“点击头像可以进入账户设置”，没有验证页面内部按钮，因此入口测试虽然通过，不能证明账户设置功能可用。

修复前 `AccountPage` 中以下控件只有视觉样式，没有事件处理：

- 个人资料、安全、常用旅客、通知偏好、支付与授信五个菜单。
- 更换头像、保存修改、修改密码。
- 页头“当前企业”和“帮助与支持”。

表单同时使用 `defaultValue`，没有受控状态、验证、保存结果或错误反馈。这是占位 UI 被纳入“页面已完成”结论造成的测试覆盖缺口。

## 修复内容

- 五个账户分区改为受控切换，并提供明确选中态与 `aria-current`。
- 个人资料改为受控表单，补手机号、邮箱校验、保存反馈和语言同步。
- “更换头像”接入文件选择器、图片类型与 2 MB 大小校验及预览。
- “修改密码”与“双重验证”增加可访问弹窗；明确 Sandbox 不会伪造真实身份系统变更。
- 常用旅客的英文姓、英文名分开保存；补齐旅客类型、性别、出生日期、国籍、护照号、签发国家/地区和有效期。
- 护照号仅脱敏展示；校验英文姓名字符、护照号格式、出生日期与有效期。
- 机票乘机人页同步使用 `surname` / `givenName`，向 F-Link 创建订单时不再从组合姓名字符串拆分。
- 通知偏好支持三个受控开关和保存反馈。
- 支付与授信支持查看财务结算、授信调整表单与校验；明确真实审核服务尚未接入。
- 页头企业按钮增加企业菜单；帮助按钮增加支持面板和业务跳转。
- 补齐桌面及 390 × 844 移动端布局。

## 尚未完成的生产能力

本轮修复使页面交互可用并可验证，但以下操作仍只保存在前端 Sandbox 会话，不能作为生产持久化证明：

- 常用旅客写入真实用户数据库；护照等敏感个人信息需字段级加密、脱敏查询、最小权限和审计。
- 个人资料与头像已写入本地 SQLite；生产环境仍需接入真实登录用户 ID、对象存储/CDN、病毒扫描和头像生命周期策略。
- 密码修改、双重验证与企业 SSO/身份服务联动。
- 通知偏好写入消息中心并驱动短信、邮件或站内信。
- 授信调整进入真实审批、额度变更和审计流程。

上线前需要为上述能力补后端接口、权限校验、审计日志和 CI 浏览器端到端测试。
