# FusionGo 全局功能冒烟测试用例

日期：2026-08-03  
范围：全局导航、账户、常用旅客、通知、订单、客户、定价、财务与基础可访问性；不包含性能测试。

## 验收原则

- “页面能打开”不能代表页面内部功能通过。
- 修改与保存类功能必须验证：提交成功、服务端落库、刷新保留、跨页面同步和错误反馈。
- 导出类功能必须验证：按钮可用、下载产生、文件名/编码/表头/行数/金额正确。
- 无法由分销端单独构造的供应商场景标记为“依赖供应商”，不得记为通过。
- 供应商应提供标准测试用例、可重复测试数据、预期状态流转、异常码和回调报文参考。
