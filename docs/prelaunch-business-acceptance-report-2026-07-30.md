# FusionGo 业务功能与上线前验收报告

日期：2026-07-30  
环境：本地前端 + 本地 API + FCG Sandbox  
结论：本地业务功能验收通过；当前不满足生产发布条件，外部阻塞项见文末。

## 本轮完成

### 订单与供应商链路

- G-Link 酒店维持强制链路：
  `lowestPrice → productDetails → availabilityCheck → 二次 availabilityCheck → createOrder → payOrder → Webhook / orderDetail → cancelOrder`。
- 新增订单生命周期维护任务：
  - 默认 30 分钟未支付自动调用供应商取消；
  - `PROCESSING` 订单按默认 15 分钟间隔低频查单补偿；
  - 已确认、已出票、已取消和失败终态停止补偿；
  - 每次任务运行保存扫描、成功、失败及明细记录。
- 酒店和机票创建订单均在不可逆供应商调用前保存本地订单和
  `Idempotency-Key`，重试不会重复创建本地业务单。
- F-Link 在搜索 `priceKey` 验价提示“价格已更新”时，自动调用
  `flight.cabin` 提取新 `priceKey`，再逐一执行 `flight.verify`。
- 供应商原始成本、客户售价和本地增值服务金额分开保存。

### 客户、定价与财务

- 客户管理已从占位页改为数据库业务：
  - 新建企业客户；
  - 启用/停用；
  - 联系人与授信额度；
  - 停用客户不能创建订单。
- 定价策略已从占位页改为数据库业务：
  - 酒店、机票或全部产品；
  - 百分比加价或固定服务费；
  - 优先级和启停；
  - 启用规则实时作用于搜索价、验价与订单售价；
  - 供应商成本不被加价规则覆盖。
- 财务结算已从占位页改为真实流水：
  - 支付流水按订单幂等入账；
  - 取消已支付订单生成退款待处理流水；
  - 历史支付迁移后自动回填；
  - CNY、USD、HKD 分币种统计，禁止直接相加；
  - CNY 企业授信支付校验额度并扣减；
  - 生产环境默认拒绝使用 CNY 授信直接支付外币订单。
- 财务流水支持 CSV 导出。
