## 问题 1：发送图片后无法复制图片

| 字段 | 内容 |
|---|---|
| 编号 | TRAE-ISSUE-001 |
| 发现日期 | 2026-08-06 |
| 严重程度 | 中 |
| 状态 | 未解决 |

### 问题描述

在 Trae 对话中发送/上传图片后，无法对已发送的图片执行复制操作（右键复制、快捷键 Ctrl/Cmd+C 均无效）。

### 复现步骤

1. 在 Trae 对话窗口中上传或拖拽发送一张图片。
2. 图片发送成功并显示在对话中。
3. 尝试右键点击该图片，选择"复制"。
4. 或尝试选中图片后使用 Ctrl/Cmd+C 复制。
5. 粘贴时发现剪贴板中无图片内容。

### 预期行为

已发送的图片应支持复制操作，用户可以通过右键菜单或快捷键将图片复制到剪贴板。

### 实际行为

所有复制途径均无效，剪贴板中不包含图片数据。

### 环境信息

- 工具：Trae IDE
- 日期：2026-08-06
